# Hider
A steganography tool using python. you can hide your text or any file in a file.

---

## How to Bind

### 1. Select Main File

Select the **main file** you want to use. You can choose any type of file.

### 2. Select Bind Type

Choose the bind type:

* **Text** — Bind text with the main file.
* **File** — Bind another file with the main file.

### 3. Bind Text

If you select **Text** *(default)*:

1. A text box will appear.
2. Enter the text you want to bind.
3. Click the **Bind** button.

### 4. Bind a File

If you select **File**:

1. The text box will be disabled.
2. Click the **Second File** button.
3. Select the file you want to bind.
4. Click the **Bind** button.

---

## Extract

### 1. Select Bind File

First, select the **bind file** from which you want to extract the content.

### 2. Select Extract Type

Choose the extract type:

* **Text** — Extract stored text.
* **File** — Extract a stored file.

### 3. Extract Text

If the bind file contains **text**:

1. Select the **Text** option.
2. Click the **Extract** button.
3. The extracted text will appear in the text box.

### 4. Extract a File

If the bind file contains **a file**:

1. Select the **File** option.
2. Enter the output file name **with its extension**.

   * `flower.jpg`
   * `video.mp4`
   * `document.pdf`
3. Choose where to save the output file.
4. Click the **Extract** button.
